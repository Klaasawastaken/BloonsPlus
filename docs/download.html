BEFORE YOU INSTALL

A few things to have ready.

01

A Windows PC.

The app and installer target Windows. Guest setup needs compatible virtualization and the required Windows features.

02

Your Steam game.

You need an owned copy of Bloons TD 6. Sign in through Steam inside the guest and complete Steam Guard there.

03

An internet connection.

Setup downloads dependencies and VM components. System installation steps may request administrator access.

New to Bloons+?

Follow the setup steps, check the guest connection and try one map before a long sweep.
