# Bloons+ Preview 4

This prerelease updates the app diagnostics and the Bloons+ website. The Windows installer is attached to the GitHub release.

## Changes

- The sidebar now shows Monkey Money per hour and XP per hour from successive read-only VM profile snapshots. Rates appear after enough live data has been collected.
- Hero-picker confirmation failures are grouped as navigation bugs in route diagnostics.
- The website adds BTD6-inspired art across Features, About, Contributors, Wiki and Subscriptions, with smoother same-site navigation.
- Subscriptions now presents Free forever and planned Pro pricing of **$5.99/month** or **$40 lifetime**. The planned Pro date is **31 October 2026**. No Pro checkout or entitlement is available in this preview.
- A prioritized [repair roadmap](TODO.md) tracks the remaining replay, route, progress, installer and site work.

## Known limits

Some route placements, hero selection, cash/round recognition and medals still need live confirmation. A listed route is not a guaranteed win. This build has passed source checks and package creation, but has not completed a clean Windows install and full sweep on a second PC.

## Install

Download `BloonsPlusSetup.exe`, compare its SHA-256 hash with `SHA256SUMS.txt`, then run the installer. BTD6 and Steam remain separate installations. See the [download guide](https://bloonsplus.com/download/) for setup steps.
