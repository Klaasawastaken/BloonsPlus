# Bloons+ 0.1.0 Preview 5

This preview focuses on replay reliability, clearer product pages, and a safer update path.

## Highlights

- Improved cash and round HUD recognition when tower panels are open.
- Added stronger hero picker verification and route failure diagnostics.
- Prevented completed failed route hashes from looping after a restart.
- Preserved Glacial Trail action timing during freeze cycles instead of releasing future actions early.
- Added support for explicit route ability actions.
- Added monthly and annual Bloons+ Pro previews with an accessible billing switch.
- Expanded the Features page with live viewer, replay control, resume, and diagnostic capabilities.
- Added frozen, temple, and city map artwork plus a refreshed README banner.
- The Download page resolves the latest installer asset from GitHub releases automatically.

## Install

Download `BloonsPlusSetup.exe` and run it over an existing installation, or use it for a new setup. Internet access is required for dependency and VM downloads. Steam and an owned copy of Bloons TD 6 remain separate.

## Known limits

This is preview software. Route availability does not guarantee a victory, especially after game balance changes or with different account unlocks. Boss execution and the complete automatic tower-unlock loop remain unfinished. Glacial Trail timing has a new safeguard but still needs a complete live validation run.

Bloons+ is independent of Ninja Kiwi.
