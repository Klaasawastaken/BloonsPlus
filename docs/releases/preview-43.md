# Bloons+ Preview 43

## Surplus spending respects owned upgrades

The replay receives a read-only per-tower path-tier snapshot derived from Profile.Save when it launches. Optional surplus purchases stay within contiguous owned tiers, using the same upgrade-name aliases as route preflight. Unknown catalog names do not authorize optional purchases. Unavailable profile snapshots retain the existing live panel checks.

Recorded route commands and game saves are unchanged. Each new replay refreshes the snapshot; purchases made during an active replay apply to its successor.

Offline checks cover renamed upgrades, Buccaneer prefixes, missing lower tiers and malformed payloads. The live VM profile produced caps for all 25 tower types in the replay catalog. Live purchase behavior under this new snapshot remains unverified until deployment and missing-medal gameplay.

Includes Preview 42 Settings, active T5 limits and waiting-log throttling. V1.0 coverage and clean-install acceptance remain open.
