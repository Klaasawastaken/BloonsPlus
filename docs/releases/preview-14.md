# Bloons+ Preview 14

## Settings and upgrade recovery

- Simplify Settings around Appearance, VM setup and backups. Remove the inert queue toggle; queues remain saved automatically.
- Collapse optional installation checks and ISO selection. Move detected profile, hotkey and learning information into Run logs.
- Apply the restored theme immediately after importing or resetting preferences.
- Never send an upgrade hotkey when the observed path button is unavailable. Preserve the exact target for the existing bounded recovery and log `button-unavailable`.
- Keep already-owned target recognition and the single visually justified purchase retry.

## Verification

## Install

Download **BloonsPlusSetup.exe**. Close Bloons+ before updating; update the VM between replays from Settings on your main PC. This is a preview, not production 1.0.
