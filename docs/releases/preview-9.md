# Bloons+ Preview 9

## A cleaner app

- Settings now groups appearance, VM setup and backups. Profile details and experimental learning are expandable.
- Search large dropdowns and choose options with your keyboard. Menus stay usable while live status updates arrive.
- Dark mode has consistent control surfaces and clearer contrast.
- Boss Events has a refreshed preview with official BTD6 art. Boss automation is still coming soon.

## Included automation safeguard

Recorded support positions remain unchanged unless experimental placement is explicitly enabled. CHIMPS and changing-terrain maps retain recorded support positions. Failed-placement recovery remains available.

## Install

Download **BloonsPlusSetup.exe** below. Close Bloons+ before updating. VM updates should run between replays through Settings on the main PC.

This is a preview, not production 1.0. Setup downloads required runtime components; Steam sign-in and ownership of BTD6 are required. Existing medals and game saves are not modified by installation.
