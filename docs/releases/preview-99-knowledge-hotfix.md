# Bloons+ Preview 99 — Monkey Knowledge Activation Hotfix

## Additions

- Read individually disabled Monkey Knowledge points from each account's save.
- Show partly enabled knowledge and active/inactive labels for purchased points.
- Add synthetic save, route, launch-flag and app-label regressions; no personal stats are included in the fixtures.

## Changes

- Require active knowledge for knowledge-dependent routes, including Master Double Cross.
- Use active Bonus Monkey and Bonus Glue Gunner points for free-placement assumptions. Existing live placement confirmation still applies.
- Preserve owned points separately from activation, retain older saves without per-point switches, and keep malformed data unknown.
- Keep game and save files read-only. Ship Capture, Sniper Paragon support and Psi title recognition remain separate unfinished work.

## Removed

- Remove the assumption that a purchased knowledge point is active whenever the global switch is enabled.
