## Additions

- Native Windows installer with bundled application and Python bootstrap, verified runtime installation, repair and interruption recovery.
- Guided first-launch setup for the visible BTD6 VM, with readiness checks and a live screen viewer.
- Missing-medal automation with account-bound medal history, persistent route failures and candidate fallback.
- A guarded boot-store recovery for new Windows guests affected by the App Sandbox boot-file failure.

## Changes

- Unified application, installer and website branding, including both Windows application icons.
- Improved settings, light and dark themes, dropdowns and first-launch configuration.
- Improved replay placement, upgrade, hero-selection and HUD safeguards.
- Updated documentation, community contribution guidance and third-party license notices.

## Removed

- Private account data, credentials, personal logs and screenshots from public distribution.
- Unfinished route drafts and private Discord bot sources from the installer.
- Separate checksum-file release assets.
