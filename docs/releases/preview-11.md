# Bloons+ Preview 11

## Runtime setup recovery

- Microsoft C++ runtime downloads now show progress and use bounded network waits.
- Incomplete downloads, oversized responses and HTML error pages are rejected before launch.
- If Windows runtime installation exceeds 15 minutes, setup reports the process and asks you to check Windows dialogs. Bloons+ does not terminate the system installer.
- Includes the cleaner Settings, searchable dropdowns, dark-mode fixes and Boss Events preview from Preview 10.

## Verification

Compiled offline payload checks, idle/controller ownership guards and atomic installer output checks pass. These checks do not install software or control BTD6. Clean Windows/VM installation is not yet fully verified.

## Install

Download **BloonsPlusSetup.exe** below. Close Bloons+ before updating. Update a connected VM between replays from Settings on the main PC.

This is a preview, not production 1.0. Setup downloads required components; Steam sign-in and ownership of BTD6 are required. Original CHIMPS recordings and BTD6 saves remain untouched.
