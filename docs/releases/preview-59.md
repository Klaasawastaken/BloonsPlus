# Bloons+ Preview 59

## Replay reliability

- Ambiguous ordinary-tower placements now require a newly opened base-tower upgrade panel before being marked confirmed. This covers free placements and purchases whose cost is masked by in-round income.
- Old panels, held placement previews and already upgraded towers cannot satisfy this check.
- An unavailable panel remains unverified; it does not cause blind duplicate placement or false terrain learning.
- Adds placement-panel diagnostics for investigating failed upgrades.

## Settings

Includes the simplified Connection, Appearance and Support layout, with advanced setup and reset collapsed. Unused experimental settings wiring is removed.

## Limits

Offline observer checks pass. This release does not claim every route wins, identify tower names from panel text, or alter original CHIMPS recordings. Updates apply between replays; earned medals remain excluded from the sweep.
