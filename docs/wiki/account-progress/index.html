Map medals

Supported profile readers expose medals by map and mode. Read the profile of the environment running the game. Missing data stays unknown; never infer CHIMPS or Impoppable from another medal.

Tower requirements

The selected route lists the hero and highest needed tier for each tower path. Account unlocks differ from in-game purchases. Buying an upgrade in a replay does not unlock an account upgrade.

Achievements

Supported Steam schema, unlocked bits and stat counters supply achievement state. Counters may not cover every achievement. Search and filter to find individual goals.

Refresh problems

Verify the host is connected to the correct guest and both are updated. Reopen the progress screen and inspect the logs if a save is unreadable. Avoid manually manufacturing completion state.
