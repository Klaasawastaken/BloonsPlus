Where each part runs

The main PC displays controls. The guest runs BTD6, the replay engine and relevant save readers. Simulated input remains inside the guest while you use the main desktop.

Setup checks

Settings checks installed components and can start or repair setup. Some Windows feature changes require administrator access or restart. Steam sign-in remains in Steam.

Updating

Use Update Bloons+ in VM from the main PC when no replay is active. A GitHub push does not update installed software. Confirm deployment before diagnosing old guest behavior.

SSH authentication

Permission denied indicates an identity or provisioning problem, not necessarily a crashed game. Check the selected guest, deployed SSH key and signed-in desktop. Never share private key files.
