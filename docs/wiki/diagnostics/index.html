Find the first failure

Inspect the first placement, upgrade or menu action that did not take effect. Later warnings can be consequences. Record map, mode, variation, round and app version.

START does not advance

The replay now holds START across multiple frames and checks the resulting screen. Persistent failure saves a local screenshot and slows retries. A green button alone does not prove a successful click.

Dependency errors

TensorFlow requires Microsoft’s x64 Visual C++ runtime. Install it in the guest if replay runs there. The installer checks package imports and keeps a diagnostic log for setup failures.

Report safely

Run logs offers Report an issue. It fills a GitHub draft with a redacted excerpt and lets you review before submitting. Download a redacted log for a longer report. No saves or keys are attached automatically.

On-demand VM viewer

Open Automation → Live VM screen to watch the guest game. The preview refreshes every two seconds while visible and stops polling when closed. Expand opens a larger view. This panel only displays the game; it does not send clicks or keys. Reconnecting or unavailable messages indicate that the guest screen cannot currently be captured.
