Getting started

Use Windows and a Steam account that owns Bloons TD 6. Keep internet access available for dependency downloads. VM gameplay needs compatible virtualization and supported Windows features.

Maps & game modes

Automation separates map, difficulty and variation. A route must exist and meet its restrictions. A map can be unlocked in BTD6 while its route is unavailable in Bloons+.

Read article →PROGRESS

Account progress

Supported profile readers expose medals by map and mode. Read the profile of the environment running the game. Missing data stays unknown; never infer CHIMPS or Impoppable from another medal.

Read article →GAMEPLAY

Route tools

A route specifies a map, mode, hero, placements, upgrade paths and timed actions. It depends on affordable prices, legal positions and the required account unlocks.

Read article →SETUP

VM connection

The main PC displays controls. The guest runs BTD6, the replay engine and relevant save readers. Simulated input remains inside the guest while you use the main desktop.

Read article →SUPPORT

Diagnostics & reports

Inspect the first placement, upgrade or menu action that did not take effect. Later warnings can be consequences. Record map, mode, variation, round and app version.

Read article →SUPPORT

Privacy & storage

Settings, checkpoints, logs and passive gameplay observations are local. The main PC and guest exchange status and commands. Supported save readers do not modify the game profile.
