Before installing

Use Windows and a Steam account that owns Bloons TD 6. Keep internet access available for dependency downloads. VM gameplay needs compatible virtualization and supported Windows features.

Install Bloons+

Get the installer from the official repository’s Releases page. Run it and follow its steps. Setup uses a compatible Python 3.12 installation when possible, supplies a fallback and creates an app-specific environment. It checks native packages before completing.

Prepare the game

Complete VM setup in Settings, then sign in to Steam inside the guest. Steam handles authentication and Steam Guard. Install BTD6, open it and reach its menu. Verify the connection before starting Automation.

First replay

Choose one map, difficulty and variation in Automation. Review requirements. Check the first placements and upgrades. Confirm victory and saved medal before counting a clear.
