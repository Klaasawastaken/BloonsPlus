What a route contains

A route specifies a map, mode, hero, placements, upgrade paths and timed actions. It depends on affordable prices, legal positions and the required account unlocks.

Record

Use the recorder controls below Automation’s selector. Start from the supported map-selection workflow, choose the target in BTD6 and record supported actions. Inspect the saved recording before sharing.

Generate

Generation is experimental. A generated file is a candidate strategy, not a tested win. Check tower restrictions, starting cash, camo and lead coverage, timing and placement legality.

Import & export

Exchange route files through the app’s tools. Include source, game version and target variation. Do not bundle player profiles, personal screenshots, credentials or keys.
