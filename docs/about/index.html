WHY BLOONS+

Your game deserves
a better overview.

Recorded routes, tower upgrades, map medals and VM setup can become a lot to keep track of. Bloons+ brings those pieces into one Windows companion.

The goal is a straightforward experience: know what a run needs, see what is happening and keep useful evidence when something goes wrong.

It is an independent project in active development. We keep unfinished features visible and improve the app through specific, reproducible feedback.

WHAT GUIDES THE PROJECT

Clear by design.

◎

Visibility first.

Useful logs, clear requirements and readable progress should make the next step easier.

↗

Keep improving.

Specific bugs and route evidence help move the project forward. A listed strategy is not a promised win.

◇

Respect the game.

Gameplay uses simulated input. Supported save readers are read-only. Bloons+ is not affiliated with Ninja Kiwi.
